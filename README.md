
# Wine Classification using Machine Learning

## Project Overview
This project uses Machine Learning to classify wine samples into three different classes based on their chemical properties.

## Dataset
- Dataset: Wine Dataset
- Total Samples: 178
- Features: 13
- Classes: 3

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Algorithm
Logistic Regression

## Workflow
1. Data Loading
2. Data Exploration
3. Feature and Target Separation
4. Train-Test Splitting
5. Feature Scaling using StandardScaler
6. Model Training
7. Model Prediction
8. Model Evaluation
9. Model Serialization using Joblib

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-Score

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the model:

python train.py

## Model Files
- wine.pkl: Trained Logistic Regression model
- scaler.pkl: Fitted StandardScaler
